# Responsive layout

The app works at all widths from 320px up to 32:9 ultrawide screens. The design is for a laptop first, but the player must work on a phone. Ultrawide screens get more panels, not longer lines of text.

## Rules

1. Use flex or grid with `flex-wrap` or `auto-fill`. Do not set a fixed width on a region.
2. Use `min-width: 0` on flex children that contain text, so long words do not push the layout.
3. Limit story text to `--measure-prose` (70 characters).
4. Use `dvh` units for the full page height, so the mobile browser bar does not cut the page.
5. Below 900px (`--bp-stack`), the side panel becomes a bottom sheet (BottomSheet) that peeks with one line. CSS cannot read a token in a media query, so write `900px` and refer to the token in a comment.
6. From 2200px with an aspect ratio of 21:9 or more (`--bp-ultrawide`), the map shows on the left of the player. Use both conditions, so a wide 16:9 screen does not get the map.
7. Wider than `--width-content-max`, the content stays at that width, in the center. The outer colour fills the sides.
8. The type size of story text changes with the viewport width (`--font-size-prose`).
9. On wide screens only the regions scroll, not the page. Give each scroll region `position: relative`. If you do not, screen-reader text with `position: absolute` goes outside the region and makes the page scroll.
10. Give a grid that fills the height a row of `minmax(0, 1fr)`. If you do not, the row grows with its content.

## Layout steps

| Width | Layout |
| --- | --- |
| Less than 900px | One column: the player. The side panel is a bottom sheet: "Here" in play mode, "Desk" in write mode. The desk has three tabs (Room, Notes, AI). In write mode the fragment panel is under the paragraph, and the margin notes go under their lines. |
| 900px or more | Player and side panel, side by side. The side panel is the Here panel in play mode and the room desk in write mode. When you write a fragment, the fragment panel takes the place of the desk, and the margin notes are next to the text. |
| 2200px or more, and 21:9 or wider | Map, player and side panel. The side panel has no small map, because the big map is on the left. |
| Any width, Atlas open (Ctrl+M) | The Atlas takes the place of the player: tabs, then the view (on the map: floors, map, room card). |
| More than 2400px | The same as above, in the center of the screen. |

## Examine an element

1. Open the story.
2. Select a small viewport in the toolbar.
3. Make sure that nothing overflows to the side and that all controls stay usable.
