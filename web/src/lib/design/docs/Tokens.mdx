# Design tokens

Design tokens are named values for colour, type, space, size and motion. The source is `src/lib/design/tokens/tokens.css`.

Components use only tokens. Do not use a raw colour, size or duration in a component. If no token fits, add a token first.

## Two tiers

1. **Scale tokens** are the same in all themes: space, type size, size, motion and layers.
2. **Semantic tokens** have a meaning, for example "body text" or "edge of a control". Each theme sets them. Use the semantic token, not the colour that it has now.

## Colour

Change the theme in the toolbar to see the colours of each theme.

Contrast rules (WCAG 2.2 AA):

- All text tokens have a contrast of 4.5:1 or more against `--color-surface` and `--color-surface-raised`.
- `--color-border-control` and `--color-focus` have a contrast of 3:1 or more. Use them for the edge of a control.
- `--color-border-subtle` is for decoration only. Do not use it as the only edge of a control.
